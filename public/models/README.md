# Kemet Royal: browser model assets

These assets derive from the five originally supplied GLB files. The source files are not distributed in this repository; the app runs directly with the optimized assets included here.
To rebuild, first place the five original files in `Models3D/`, then run `node scripts/optimize-models.mjs` (Node 20+, npm and network access). See the script for the required source filenames.

All models are centered approximately at the origin, use Y-up, and preserve their original scale and materials. The temple entrance faces +Z: a camera at `[1.8, 1.6, 2.3]` gives a front three-quarter view. Its geometry includes the full site, landscaping and parking, in one mesh. The eye lies on XY; the papyrus lies on XZ and should be viewed from above or rotated toward the camera.

The files use plain GLB, with no Draco, Meshopt or KTX decoder requirement. Mesh simplification preserves silhouette and UVs; texture maps are JPEG at 1536 px for the temple and 1024 px for the other objects. Tangents are omitted and generated by Three.js in the normal-map shader. The glTF validator reports no errors; its expected tangent-space warning reflects this choice. The temple also has an informational non-power-of-two texture notice, supported by WebGL 2.

Each model has a matching transparent `*-poster.webp` render of the actual optimized geometry (roughly 40–60 KB), useful as a loading image or fallback when WebGL is unavailable. The temple poster is 1400 × 1000; secondary posters are 900 × 1000. These were rendered with Blender Cycles and converted to WebP. Lazy loading secondary models is recommended; the five models together are about 14.12 MB.
